
## v4.16.1 全量代码自检 + 修复 10 个隐患（未发布上线）

- 用户请求：接手项目 → 先跑一遍全量测试 → 修 bug。全量 14/14 全绿、无失败用例、无 TODO/FIXME 残留，遂按用户选择做「主动代码自检找隐患」。
- 方法：派 3 个并行子代理静态审查 index.html（5551 行单文件），分别查「JS 运行时正确性」「DOM/id/选择器一致性」「持久化/数据完整性」，只报 CONFIRMED 真实 bug（行号/级别 P0-P2/机制/最小修复），只读不改。父代理逐条对照源码核实后修复。
- 结果：10 个真实隐患（无 P0 崩溃级），全部修复。3 个 P1 + 7 个 P2：

  持久化/数据完整性（4）：
  1. **P1 btn-wipe 清除不彻底**：删掉 12 个 localStorage key，但内存只重置 CFG/TERMS/PREFS/LAST_OUT，TM/GLOSS/PROMPTS/PROJECT/STAGE/theme/accent 仍残留 → 清除后界面显示旧数据，后续 saveGloss/savePrompts/saveProject/learnFromResult 会把残留旧数据静默写回（清除形同虚设）。修复：删 key 后 `location.reload()`，让所有模块从空 storage 重新初始化。
  2. **P2 renderDataStat 占用统计漏算**：`Object.values(LS)` 只统计 5 个 key，漏 7 个裸字符串 key。修复：改共享 `ALL_KEYS`（12 个全量）。
  3. **P2 v2 恢复无 key 白名单**：`Object.entries(j.data).forEach(setItem)` 会写入备份中任意 key。修复：加 `ALL_KEYS.includes(k)` 过滤。
  4. **P2 v1 兼容恢复污染 DEF_CFG**：`Object.assign(DEF_CFG, j.cfg)` 就地改写共享常量。修复：`Object.assign({}, DEF_CFG, j.cfg)`。

  运行时正确性（4）：
  5. **P1 术语条目 id 类型不一致**：笔记导入用字符串 id（`'t'+Date.now()+…`），renderGlossTable 用 `+dataset.id` 强转得 NaN → 编辑/合并/勾选静默失效，且污染 GID 计数器使后续导入全得 NaN id。修复：① 导入改 `id: GID++`；② GID 计算 `Number(t.id)||0` 兜底；③ 查找改 `String(x.id) === tr.dataset.id`。
  6. **P2 termAudit 正则双反斜杠**：`/[\\s·]+/g` 字符类匹配的是字面反斜杠+s，而非空白符 → 一词多译分组键保留嵌入空格漏检。修复：改 `/[\\s·]+/g`（单反斜杠）。
  7. **P2 无 API Key 跳错页签**：`$$('nav button')[2].click()` 打开「项目进度」而非提示语指向的「设置」。修复：改 `nav button[data-page="p-set"]`。
  8. **P2 CSV 导入朴素 split(',')**：含逗号的备注往返损坏。修复：改用已有的 `csvParse` 状态机。

  DOM/id/事件（2）：
  9. **P1 手动配图关键词被搜索丢弃**：手动补充的 span 只设 textContent、缺 data-zh，searchProvider 只读 dataset → 手动词不进百度/必应/Pixabay 搜索。修复：创建时补 `span.dataset.zh = s`。
  10. **P2 docModeWrap title 属性被截断**：内层 ASCII 双引号 `"待校对译文"` 提前终止 title 属性。修复：改中文引号「待校对译文」。

- 工程决策：`ALL_KEYS` 提升为单一来源（备份/恢复/清除/统计四处共用 12-key 列表，杜绝改一处漏一处）；btn-wipe 改刷新而非手动枚举 12 个内存变量（手动枚举正是 #1 的根因）。
