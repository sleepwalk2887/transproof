# 2026-10-23 开发日志

> 今天做了一件事：**v4.32.0「术语权威分级（approved 状态机）」上线**，即六机制里的 M4 / 任务板 T-012。
> 结论先说：专有译词库的词条现在分「待审核 / 已批准 / 已拒绝」三态，校对只认「已批准」的译法；
> 改了已批准的译法会自动打回待审，避免 AI 悄悄改动权威译名。

## 一、v4.32.0 做了什么（给文科生看的白话版）

以前：专有译词库里所有词条一股脑塞给 AI，待审核的、你还没拍板的，也照用不误。

现在：
| 状态 | 意思 | 校对时 |
|---|---|---|
| 待审核 | 新收录、还没审过 | 不强制，AI 可自由发挥 |
| ✅ 已批准 | 你确认过的权威译法 | **锁定一致**，全文照译 |
| 已拒绝 | 你否掉的译法 | 不注入，等于不存在 |

三个动作都在词条表格里一键完成：**✓ 批准 / ↺ 待审 / ✗ 拒绝**。
也可以让 AI 先核查——判定「正确」就一键批准，判定「错误」就采纳建议改译法（改完自动回「待审核」）。
