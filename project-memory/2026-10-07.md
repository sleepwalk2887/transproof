
## v4.11.0 防崩溃 + 区块折叠 + 可粘贴注释（发布上线）

- 用户痛点：字数一多浏览器卡死/崩溃；纠错批注和译注建议重复花 token、应默认收起。
- 根因：run()/tsRun() 流式回调每个 token 都 `md(full)+innerHTML` 全文重建 DOM，O(n²) 卡死。
- 实现：
  1. **流式渲染节流**：新增 `makeStreamRenderer(el)`，120ms 节流 + 超长(>15000字)降级纯文本 textContent（不解析 Markdown、不重建 DOM），结束再一次性 md() 渲染。run/tsRun 都改用。
  2. **区块折叠**：新增 `collapseSections()`，把「逐条批注/注释建议/术语争议/待确认」用 <details class=sec-fold> 默认折叠，「修订后译文」主动显示。错误分类点击某类自动展开对应折叠块。
  3. **注释可粘贴格式**：note 模板改为输出「编号尾注」① 译名注/背景注/歧义注（定位）正文，可直接粘贴进文档；hard 加"批注注释从简"铁律。
- 版本 4.10.0 → 4.11.0。tests/10-collapse-stream.js（4 用例）。全量回归 01-10 零失败。

## v4.13.0 流式渲染重构（纯文本 · 修火狐卡顿）（发布上线）

- 用户反馈：火狐下"单独一个章节"都卡。之前 v4.11.0 只做了节流+超长降级，仍卡。
- 排查：火狐 headless 引擎与 playwright 协议不兼容（秒退），改用代码分析。锁定三处性能瓶颈：① 流式每 150ms 仍 md() 全文解析 + innerHTML 重建 DOM；② `el.scrollTop = el.scrollHeight` 每次读高度再写，触发火狐强制同步布局（forced reflow）；③ 火狐对 innerHTML 重建敏感。
- 修复：`makeStreamRenderer` 改为**流式一律纯文本**（`el.textContent = latest` + `el.style.whiteSpace='pre-wrap'` 保留换行），零 Markdown 解析、零 DOM 重建、零滚动；150ms 节流。结束后由 run()/tsRun() 恢复 `whiteSpace=''` 再 `md(text)` 渲染一次。
- 同时确认无旧火狐不兼容语法（replaceAll/at/??=/||=/findLast 等均无）、scrollTop 已全部清除。
- 版本 4.12.0 → 4.13.0。全量回归 01-11 零失败零报错。已发布线上 v4.13.0，链接不变。
- 遗留提示：若用户仍卡，可能非渲染问题而是①用了 deepseek-reasoner 推理模型（很慢）②网络/扩展拦截。建议用户观察"是页面无响应还是字慢慢吐"来区分。
