
## v4.21.0 Swiss × NASA-punk 融合 UI 改造（全站，已上线）

- 需求链：用户提「瑞士国际主义风格（Swiss Style）」8 条规格（12 栏网格 / 无衬线只用常规+粗体 / 标题极大正文极小 / 左对齐 ragged right / 不对称留白 / 黑白+单强调色平涂 / 细线+编号点缀）→ 先试点（全局配色 + 校对工作台）→ 用户反馈「感觉只是调整了颜色」→ 提 NASA-punk 规格（70s NASA 规范手册 + 《星空》界面：米灰 #ECE5D6 底、细线分面板+铆钉、黑白警示斜纹+全大写小号编号、四色复古彩条/圆形徽章、唯一强调红 #D63A2C、轻使用痕迹、禁霓虹/渐变）→ 用户定调「两种风格都要融合但不能太怪异」→ 用户追加「铆钉太弱改一下、字体选硬朗风、做完直接更新到全站」。
- 融合思路：骨架取 Swiss（网格 / 左对齐 / 平涂 / 细线 / 编号 / 无衬线），点缀取 NASA（面板 / 标签 / 彩条 / 徽章 / 等宽 / 强调红），克制不过度。**主动砍掉 NASA 最易翻车的「贴纸 / 手写批注 / 划痕做旧」三样**（一加就脏，跟 Swiss 克制打架）。
- 实现（工作副本 `C:\Users\Andrew\.dsh\dsh_orb\transproof\index.html`，改动集中在 `<head>` 字体 + `:root` 配色 + `</style>` 前追加的「Swiss × NASA-punk 融合覆盖层」11 条，零 JS 结构改动、纯 CSS）：
