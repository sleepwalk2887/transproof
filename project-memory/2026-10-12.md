## v4.21.2 扫描件 OCR 修复：语言包同源 + worker/core 镜像探测（已上线）

- 背景：v4.21.1 上线后用户仍报「又显示解析失败了？？？之前pdf扫描都好好的」「解析失败undinfined」。文字型 PDF 双路复现均成功 → 失败集中在**扫描件 OCR 路径**。
- 根因（两层，均有源码/复现证据）：
  1. **worker 死 → toast「解析失败undefined」**：v4.21.1 的 loadLib 多源只救了 tesseract 主脚本，**worker/core/lang 三个内部路径仍硬编码 jsdelivr**（`tesseract.js@5.1.0` 源码 `worker/browser/defaultOptions.js` 的 workerPath、`getCore.js` 的 corePath 默认、createWorker 默认 lang 模板）。jsdelivr 被墙 → `spawnWorker` importScripts 失败 → `worker.onerror` → `createWorker.js` 里 `workerResReject(event.message)`，**event.message 是 undefined** → 用户看到的「解析失败undinfined」。
  2. **lang 挂起**：语言包 `chi_sim.traineddata.gz` 走 jsdelivr `ERR_QUIC_PROTOCOL_ERROR` 失败 → `loadLanguage` reject 被 `.catch(()=>{})` 吞掉 → workerRes 永不 settle → 界面卡在「OCR 识别…95%」无任何 toast（本机复现）。
- 修复（工作副本 index.html，v4.21.2）：
  1. `TESS_CANDIDATES` + `tpReachable`（fetch 普通 GET 拿响应头即 cancel，8s 超时，避开 Range 预检）+ `tpTessPaths`（Promise.all 三路探测，结果缓存 `__TP_LIBS.tessPaths`）：workerPath/corePath 候选 = unpkg → npmmirror → jsdelivr（HEAD 全验证 200 + 合规 JS MIME：text/javascript / application/javascript；npmmirror 语言包 scoped 路径 403 不收）。
  2. **langPath 语义坑**：tesseract worker 源码 `loadLanguage` 中 `langPath || 默认(每语言 ${lang}/4.0.0_best_int)`，**用户传 langPath 后拼接是平铺 `${langPath}/${lang}.traineddata.gz`**（单值服务所有语言，npm 每语言分包布局拼不出来）。方案：**把 `chi_sim.traineddata.gz`(1718768B) + `eng.traineddata.gz`(2952873B) 下载到应用同源目录**（md5 26E38512…/FC3FD803…，gzip 魔数 1F8B 已验证），langPath = `new URL('.', location.href)` 当前目录；同源探两个文件都 200 才用，探不到则不传 langPath 回落厂商默认（jsdelivr 每语言布局，非封锁用户可用）。**零 CDN 依赖、最快、不会被墙**。
  3. `tpRecognize(image, onOcrProgress)`：loadLib 主脚本(unpkg 优先) → tpTessPaths → `Tesseract.recognize(image,'chi_sim+eng',{logger, errorHandler, workerPath, corePath, langPath})` + **240s 看门狗**（超时 throw「OCR 数据下载超时（语言包/内核），请检查网络后重试」，杜绝永久挂起）+ `errorHandler: e=>console.warn`（否则 createWorker onmessage 内 `throw Error(data)` 产生 pageerror）。3 个调用点（ocrPdfPage / parsePdfAsScan / parseImage）全改走它；`ocrPdfPage` 加可选进度回调，parsePdf 传 `TESS_STATUS_ZH`（loading tesseract core→下载OCR内核 / loading language data→下载OCR语言包 / initializing tesseract→初始化OCR / recognizing text→OCR识别中）到 fileBar。
  4. `errMsg(e)` helper（null→未知错误 / string 原样 / e.message / e.type→内部错误 / JSON 兜底）替换 3 处「解析失败：」的 `err.message`（1748 配对预览 / 2075 tsOnSrcFile / 3280→3357 onFileChosen），杜绝再显示 undefined。
- 验证：复现探针 `_probe-pdf.js` 扫描件 PDF → toast「已解析：1 章节，12 字」、fileBar「PDF（扫描件）· 1 章节 · 1 页 OCR」、11 秒完成、0 console/page error（网络列表里的 ERR_ABORTED 全是探针/探测主动 cancel 副作用）。全量 `run-all.js` **22/22 全绿**（新增 `tests/22-ocr-paths.js`：tpTessPaths 断言 worker/core 候选 ∈ 列表且可达、langPath=同源、两语言包可达 + 扫描件端到端成功 toast/无 pageerror）。
